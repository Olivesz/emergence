Logic from gliders

Conway's Game of Life — one level below Wireworld. No wires, no clock, no signals built into the rules. Just 3 to be born, 2 to survive. A glider is the signal; a glider gun is a signal source; where two gliders collide, that's a logic gate. Everything you see obeys only that one rule.

The gates here are the same reactions verified cell-by-cell in glider-logic/gates.py. NAND is universal, so the same logic that runs the Wireworld CPU could, in principle, stand on these glider gates — computation all the way down.
